# Maktab ta'limidagi muammolar - README

This project is a complete Remotion + React + TypeScript source for the Uzbek motion-graphics video "MAKTAB TA’LIMIDAGI BA’ZI MUAMMOLAR...".

Files created:
- package.json
- tsconfig.json
- remotion.config.ts
- src/index.tsx
- src/Video.tsx
- src/script.ts
- src/styles.css
- src/components/* (Card, DrawSVG, TypingText)
- src/components/illustrations/* (5 distinct illustrations)
- src/scenes/* (all scenes in required order)
- scripts/generate-sounds.js
- assets/sounds/ (generated by script)

Install and preview:
1. Install dependencies:
   npm install
2. Generate sound assets (this will create the local .wav files used by the project):
   npm run generate:sounds
   (Note: package.json runs this as "prepare" too if your npm version runs prepare automatically)
3. Start the Remotion preview:
   npm run dev

Render the full video to the suggested path:
   npm run build

Notes and limitations:
- I could not run the actual TypeScript compiler or Remotion preview in this environment; please run the install and the generate script on your machine before previewing.
- Fonts: the project uses system UI fonts for legal simplicity. If you want a custom font, place it in assets/fonts and update src/styles.css.
- Audio generation: sounds are synthesized locally by scripts/generate-sounds.js; run it to produce the .wav files.
- Composition previews: each scene is a separate Remotion Composition. You can preview a specific scene by opening the preview and choosing its composition id (e.g., "maktab", "t1", "comp"). The "Main" composition is a placeholder.

If you want, I can now run a limited linter or add a bundled npm script to produce a single composition sequence that matches the full timeline; tell me if you prefer that single-composition output as the default "Main" composition.
